# 算法课例 · 有序数组的左边界

自拟课例。前置是数组下标、循环和非递减顺序。目标是返回第一个大于等于目标值的位置，若找不到则返回数组长度，并用不变量验证重复元素和边界。

在有序成绩表里寻找第一条及格记录。用半开区间 `[lo, hi)` 表示还未排除的元素。每轮开始时，`lo` 左侧元素都小于目标，`hi` 及其右侧实际存在的元素都大于等于目标。初始化时这两个已分类区间为空。检查中点后，排序使我们能一次排除中点一侧。

~~~text
lo = 0
hi = len(a)
while lo < hi:
    mid = lo + (hi - lo) // 2
    if a[mid] < target:
        lo = mid + 1
    else:
        hi = mid
return lo
~~~

如果中点元素偏小，可排除中点及其左侧，把 `lo` 移到中点之后。否则中点及其右侧都符合比较条件，把 `hi` 移到中点，保留中点作为已知符合位置。每次区间长度至少减少一项，结束时 `lo == hi`。它左边都不符合，它所指位置在数组内时必符合。额外空间为 $O(1)$，比较次数为 $O(\log(n+1))$。

| 任务 | 分析与验证 |
| --- | --- |
| 普通命中 | 对 `[1,3,5,8]` 查找 5。区间依次为 `[0,4)`、`[0,2)`、`[2,2)`，返回 2。核对左邻 3 小于 5，且位置 2 的值为 5。 |
| 重复元素 | 对 `[1,4,4,7]` 查找 4。先比较下标 2 和 1，令上界依次变为 2 和 1，再检查下标 0 后返回 1。相等时继续向左缩小区间才能找到最早位置。 |
| 查找插入位置 | 对 `[1,3,9]` 查找 4。先排除下标 0、1，再将右边界缩到 2。返回 2。插入后左邻 3、右邻 9，顺序保持。 |
| 哨兵与空输入 | 对 `[2,5]` 查找 9，比较后 `lo` 变为 2，此时停止且不访问下标 2。空数组初始化即停止，返回 0。两者均满足返回数组长度的契约。 |
| 排序条件不成立 | 在 `[4,1,5]` 查找 4 时，中点的 1 会导致排除左侧的 4。若任务是返回原序列中首个匹配位置，可在线性扫描时保留原下标，每次查找最坏需比较 $n$ 次。 |

比较式决定了边界。遇到相等就返回可能错过更早位置。循环条件写成 `lo <= hi` 会令空区间也进入循环。下节可把比较式改为寻找严格大于目标的位置，并用两个边界计算重复项数。

## 独立练习

- 基础一｜逐轮跟踪 `[2,4,6,8,10]` 查找 7。
- 基础二｜逐轮跟踪 `[5,5,5]` 查找 5，检查返回位置。
- 进阶一｜构造一个使“相等就返回”失败的数组，写出验证条件。
- 进阶二｜设计空输入、目标小于最小值和大于最大值的测试并写出期望结果。
- 综合｜将“首日达到库存阈值”转写为边界查找。解释输入必须满足的条件和找不到时的语义。
