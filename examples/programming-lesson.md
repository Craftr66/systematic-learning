# C++ 课例 · 值传递、引用与接口语义

自拟课例。适合有编程经验且已能读 C++ 函数、整数及变量作用域的学生。目标是通过对象关系预测调用后的状态，并按接口意图在值传递、可写引用和只读引用间选择。过程适用于 C++17。以下输出为语言规则推导的预期。

~~~cpp
#include <iostream>

void by_value(int x) {
    ++x;
}

void by_reference(int& x) {
    ++x;
}

void observe(const int& x) {
    std::cout << x << '\n';
}

int main() {
    int n = 7;
    by_value(n);
    std::cout << n << '\n';
    by_reference(n);
    observe(n);
}
~~~

## 预测并验证

值形参为独立对象。引用形参绑定现有对象。可写引用允许通过该形参修改对象，只读引用限制通过该形参执行的操作，其他可写访问仍可改变同一个对象。

1. **只改局部值**。第一次调用后形参从 7 变成 8，形参生命周期随调用结束。打印 `n` 得 7。画出两个对象并核对哪个被递增。
2. **显式修改调用者**。第二次调用中的 `x` 与 `n` 是同一个对象的两个名字，`n` 变为 8。第三次调用读取并打印 8。用每一行的状态核对最终两行输出。
3. **通过形参只读**。在 `observe` 中尝试添加 `++x;` 会导致编译诊断，因为该表达式试图经只读引用修改它所指的整数。保留原版做正例，再用单独文件做编译反例。
4. **实参是临时值**。`by_reference(3);` 无法绑定到要求可修改左值的形参。`observe(3);` 可在这次调用内读取临时整数并打印 3。用各自独立的调用位置核对预期。
5. **表达接口意图**。若希望保留原值并得到递增结果，可以写 `int incremented(int x) { return x + 1; }`，接收返回值。用小整数 7 测得预期是调用者原值 7、返回值 8。若合同明确要求更新调用者，使用可写引用。此处输入范围需避免有符号整数溢出。

可执行验证方式是将示例保存为 `lesson.cpp`，在具备 C++17 工具链时执行 `g++ -std=c++17 -Wall -Wextra lesson.cpp -o lesson`，再通过当前终端运行生成的可执行文件。编译反例应单独保存。

## 小结和练习

先读接口有没有更新调用者的意图，再考虑独立副本、只读访问和复制代价。大型只读对象常适合引用，对小整数按值通常更直接。引用能否安全逃逸到调用之外取决于对象生命周期，后续课再讨论。

- 基础一｜预测两次 `by_value(n)` 后的值并解释。
- 基础二｜预测两次 `by_reference(n)` 后的值并解释。
- 进阶一｜从三种形参中选择适合“报告一个 `int`，保证通过形参不修改”的写法，并说明选择。
- 进阶二｜改写一个可写引用函数，让调用表达式返回新值，检查调用者原值。
- 综合｜给“返回调整值”和“更新原计数器”分别设计函数接口与两个测试，解释两者的副作用。
