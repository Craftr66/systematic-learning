# 教学标准

## 需求与路线

从用户已提供的信息开始。只追问会改变诊断、近期课程或可行性的事项，必要时合并提问。了解主题与边界、学习目的、目标能力、当前基础和经验、每周投入和周期、考试或求职或交付约束、可用软硬件与偏好。明确任务可直接开课，欠缺的信息和假设随实际学习补齐。需要验证起点时用 [评估与反馈](assessment.md) 的诊断规则。

依据条件和诊断证据拆分学习阶段。每阶段明确预计时间、可观察成果、前置依赖、课程顺序、练习与实践、考核和晋级标准。安排综合任务验证多项知识的联用或迁移。以时间区间估算，标明影响估算的条件。证据不足时先制定近期可执行安排和暂定阶段路线，后续记录调整及原因。落盘时可用 [路线模板](../assets/roadmap-template.md)。

## 决定本轮教什么

以学员本轮指定的动作、时间和学习目标为准。用户要求直接作答、批改或讲解某一题时，及时完成该动作。复验分流用于需要决定是否推进课程的场景。

| 开课时掌握的证据 | 本轮动作 |
| --- | --- |
| 有未交作业或复验题，且它仍对应本轮目标 | 接回原题和作答要求。独立验证时先等作答，答案留待提交后。较长作业可以先接续与本轮目标相关的部分，把其余题保留在档案中。 |
| 前置知识有近期独立通过的证据 | 进入依赖它的下一内容，用新的任务继续收集证据。 |
| 关键前置的独立证据不足、已有错误但尚未复验，且没有可直接接回的题 | 出一道能区分最可能错因的短题。让答案与关键理由都可观察，收到作答后按 [评估与反馈](assessment.md#依据作答选择下一步) 决定去向。 |
| 本轮已经看到了同一关键错误，或学员明确请你重讲 | 根据已有证据补最小缺口，再用一道尚未讲解的变式复验。把依赖它的课程保留为后续任务。 |

课时紧张时，围绕一个可在本轮完成的目标安排内容。已经通过复验且仍有时间，可开启下一课；否则把下一步写清楚。完整正式课的例题量适用于完整课时，短课选最能区分理解的例题与练习，并保留尚未完成的教学目标。学员明确选择跳过某项前置时，按 [评估与反馈](assessment.md#掌握状态与晋级) 记录。

## 正式课程

下列内容按学科、阶段和复杂度组织，标题和篇幅可灵活处理。一次讲不完时按完整子目标拆课，指明本节边界和后续承接。

1. **前置与目标**。交代用途、在路线中的位置、与上一课的关系和可验证目标。关键前置证据不足时，用短问题核查，或在本课补上。
2. **概念**。从问题、实例或应用进入，经直观含义过渡到严谨定义。解释术语、符号、变量和相近概念。有帮助时用结构图、函数图、流程图、时序图或状态变化图展示抽象关系。
3. **原理与推导**。展示关键因果、公式推导、运行过程或组件交互，交代成立条件、边界、例外和局限。逐步说明学生尚未掌握的关键过程。已验证掌握的次要步骤可简化。
4. **方法选择**。显式训练可复用的判断过程。说明先看哪些特征、如何识别问题、为何符合所选方法的条件、备选方法的取舍、条件变动或方法失效时如何调整，以及如何验算。
5. **代表例题**。复杂或核心知识点原则上提供 4–6 个有不同训练价值的例题，覆盖基础、常规、条件变化、易错、进阶及综合，可由同一题覆盖多个维度。每例给出必要分析、完整关键步骤和结果验证。简单知识点可减量。工程案例标清真实来源或合理构造。复杂课拆分时，每节例题覆盖该课目标。
6. **误区与总结**。对容易混淆的概念、遗漏条件及常见逻辑、计算或实现错误说明原因和检验方法。课末归纳核心原理、关键规则、条件、解题方法、必须掌握的能力和后续联系。
7. **独立练习**。通常安排 5–8 道分层练习，或适量的操作与项目任务。基础层查理解和操作，进阶层查识别与选择，综合层查迁移。题目以已教知识为基础，缺少必要知识时先补教或给必要提示。练习答案按用户要求或在提交后提供。

[课程模板](../assets/lesson-template.md) 可用于保存正式课，项目阶段也可选用其中适用字段。项目按里程碑组织，给每阶段写清当前知识、独立完成项、验收操作和预期证据。保持学生承担与目标匹配的操作和判断。

## 输出前检查

在输出前逐项核对并补齐欠缺。课程应解释本质与成立依据，展示关键推导、运行过程及方法选择，有足够且非重复的案例，说明条件和易错点。核查目标、阶段和前置的匹配度，检查练习的知识覆盖，以及公式、代码、事实与逻辑。保持跨会话及长课程的同等标准。复杂内容可合理拆分，质量检查无需展示分数或自检清单。
