# 评估与反馈

## 初始诊断与专项训练

选少量能区分水平的任务，覆盖与学习目标相关的概念理解、知识储备、推理和应用。可给一题多问、代码阅读、短推导或实际操作。根据结果标记掌握证据、薄弱处、缺失前置、认知误区与适合的难度。自报只用于选起点。学生明确完全零基础且测试无助于分流时，可直接从入门课获取首份作答证据。尚无作答时将判断标为待验证。

专项训练一次针对一个可观察能力。先取一个短样本，再按作答选择下一题。独立做通常规题后给变式或陌生场景。学员要求一次一题时，每次只布置一个新任务。

## 批改与跟进

1. 分开检查结论、推理或实现、验证方式。对正确答案也检查理由和条件，证据不足时用追问或短变式确认是否偶然答对。
2. 指出具体题号、步骤或代码位置。按实际原因识别概念、知识遗漏、方法、计算、逻辑或实现错误，解释最早的关键偏差。
3. 根据学员要求决定给提示、反例、验证方式还是完整正确过程。按下面的分流决定复验或继续。
4. 长期主题记录真实提交、得分依据、薄弱处、能力证据及下一步。流程见 [学习档案](learning-memory.md)。

## 依据作答选择下一步

先问自己：这次证据能区分哪两种理解？对准备依赖这项能力的下一内容，采用下列动作。

| 看到的作答 | 反馈和下一步 |
| --- | --- |
| 独立作答，结论、关键理由与适用条件均成立 | 记下证据。该前置可以支撑下一内容。若仍需验证迁移，可在新情境中另设任务。 |
| 结论正确，但理由关键处错误、缺失，或作答依赖提示 | 区分结论和过程。若表述欠清楚，先追问关键理由；有概念错误则先纠错。提示后的成功可作为练习证据，独立程度用另一道未讲解的变式验证。 |
| 偶发计算、笔误或实现失误，学员能自行定位、纠正并说明原理 | 简短反馈与核对。有足够的前置证据时，继续原课程。 |
| 前置概念、适用条件或方法选择有关键错误 | 定位最早偏差，补必要的一步。可用外观相似、关键条件不同的练习揭示误区，再用独立变式复验。依赖这一点的新课待复验证据。 |
| 同类误区复现 | 用与上次不同的表征或任务拆分。例如用成对反例代替原有口头解释，或改用逐步状态追踪。安排新的无提示复验，一次检查一个关键判断。 |

复验前明确可通过的可观察表现，例如「分别算出点值和极限，并用相邻点解释极限」。尚未作答时记录待复验。反复出现的误区即使当场独立通过，也可在后续会话安排一次主动回忆或变式，检查能否保持。

## 掌握状态与晋级

为核心知识点关联最近的有效证据及提示程度。可依据独立作答、原理解释、实践成果或变式测试更新到证据支持的状态。

| 状态 | 判定依据 |
| --- | --- |
| 未学习 | 尚未接受正式教学，且无足够表现证据支持更高状态。 |
| 已接触 | 能初步辨认概念或情境。 |
| 已理解 | 能解释基本原理和关键条件。 |
| 可应用 | 能独立完成常规问题或操作。 |
| 已掌握 | 能处理变式并解释方法与检验。 |
| 可迁移 | 能在陌生场景中主动识别并独立应用。 |

阅读课程只记录授课事实。标明有提示、合作或看答案等情况，并写明证据能支持的判断。阶段晋级优先使用路线约定的验收条件。未约定时，80% 可作为正确率参考，另查关键概念和独立应用。学生选择跳过时保留其未达成的状态、证据和待补项，必要时在后续阶段安排复验。

## 复习与考试

优先复习最近出错、关键前置、久未验证或学生反馈开始遗忘的知识。以主动回忆、重新推导、独立作答和变式为主，依据结果调整复习优先级。

考试学习按适用目标和官方大纲组织基础、强化、冲刺、模拟阶段，可依据备考周期合并。讲解可核实的考查形式、解题策略和时间分配。标明官方版本、适用范围和真实来源，原创题标为模拟，资料无法核实时标明来源状态。限时测试以实际记录的用时为准，学生自报用时须标明来源，未核验用时不得作为实际限时成绩。

先公布考核范围、任务、评分规则和允许资源。交卷前仅按测试约定答疑，答案与评分留待提交后。仅对收到的答卷或可观察成果评分，标明缺答、未测或未验证的部分。保存原始证据引用、得分与下一次验证。可用 [考核模板](../assets/assessment-template.md)。
