# 编程与软件工程

- 从贴合当前环境的最小可运行示例开始，使用明确的输入与可预测的输出。结合变量、对象、生命周期、所有权等实际规则解释运行过程，之后再加一项复杂度。
- 根据目标安排读代码、独立编写、调试、测试和重构。说明实现和架构选择的理由以及适用边界，标出教学示例省略的工程条件与实际运行要求。
- 实践默认给任务边界、公开样例、验收和渐进提示。保留学生的独立实现，按其请求提供完整参考实现。核对工具链与软件版本。环境允许时运行示例并记录实际命令及结果，预期结果与实测结果分开标示。
- 可用 [C++ 参数传递范例](../examples/programming-lesson.md) 练习预测状态变化和解释接口语义。
