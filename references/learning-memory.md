# 学习档案与跨会话恢复

## 确定主题与档案位置

1. 优先使用用户指定的路径，再查当前工作区的主题目录及可识别的旧档案。可按主题或课程编号在当前授权范围搜索。若有多份合理匹配且无法辨别，只询问哪一份；用户说要继续但找不到原档案时，请其提供路径或上次记录，同时可根据已知内容继续教学。
2. 新建长期主题时，默认使用当前可写工作区中的 `Learning/<主题标识>/`。若工作区本身已明确专用于该主题，直接使用该工作区。不同主题各用一份档案，主题标识稳定且可辨认。遵循当前工作区已有规则，通用 Skill 文件只存教学方法。用户要求仅在聊天中学习时尊重该选择。
3. 新档案先建立学员档案、路线和进度，可用下表模板。其余文件在产生对应记录时创建。旧档案沿用原名、布局、编号、评分与记录格式，按需要补充最小字段。已有主题的盘点不要求整库迁移。
4. 将主题路径写在简短的课末交接中。新聊天在同一工作区可从主题目录恢复。跨工作区时使用上次给出的路径或用户指定的文件。路径不可读或不可写时说明实际限制，给出可复制的简短交接或更新，标明目前未落盘的部分。

| 档案 | 建立或更新时机与职责 |
| --- | --- |
| `StudentProfile.md` | 初始化记下目标、自报基础、诊断证据、时间和环境。使用 [学员档案模板](../assets/student-profile-template.md)。 |
| `Roadmap.md` | 初始化建立路线，随诊断或表现更新阶段，并记调整日期、证据和原因。使用 [路线模板](../assets/roadmap-template.md)。 |
| `Progress.md` | 初始化与每次完成授课、批改、考核或实际复习后更新。保存当前阶段、课次、状态、待提交项、下一动作及证据链接。使用 [进度模板](../assets/progress-template.md)。 |
| `KnowledgeMap.md` | 需要独立跟踪较多知识点时记录稳定编号、依赖、状态、证据和待验证项。小主题可使用进度模板中的能力表。 |
| `Mistakes.md`、`Review.md` | 有真实错误或待复习项时使用 [错题模板](../assets/mistakes-template.md)。简单主题的复习队列可直接存于进度。 |
| `Lessons/`、`Exercises/`、`Assessments/`、`Projects/` | 按需保存课程、实际练习与作答、真实考核记录或项目里程碑及验收。分别参见 [课程模板](../assets/lesson-template.md) 和 [考核模板](../assets/assessment-template.md)。 |
| `AGENTS.md` | 只在主题确有跨会话的专项教学规则且有合适的独立主题目录时生成，保护已有指令。 |

## 恢复一次会话

- 先读该主题的进度或等效记录，优先确认当前学习目标、课次与下一步、未交作业、待复习和最近一次关键证据。再按缺口定向读路线、知识图、错题、考核或课程资料。用户提供新任务时，用已恢复的当前状态匹配请求。
- 区分已发题、已授课、已提交、已批改与已验证掌握。接回待交题时读取题目和作答要求。要判断能否推进时，优先找与当前前置直接相关的最近独立证据。记录相冲突时核实对应原始证据，仍无法确认就标为待核实。
- 只给足以衔接的简短回顾，然后完成这次请求。只读恢复或继续未产生新成果时，按实际情况无需改写学习历史。

## 回写与检查

- 使用当前日期和已有课次、知识点、作业或考核编号关联一条学习事件。日期、分数、完成情况和能力更新应来自实际产出或明示来源。授课与独立验证单独记录。标注未测、待提交、提示程度以及自报来源。
- 有新作答、授课或实际布置了需续接的复验时，先保存或引用产物，再合并更新相关能力、错题和复习项，最后更新进度摘要。复验交接写清题号或位置、待交或已判定的状态、通过条件，以及通过或仍卡住时的后续任务。沿用旧档案中等效的字段。写入前重读目标文件的最新版本，用局部修改保留旧记录和无关条目。重试前按编号、提交或证据核对已写部分，补齐缺项，避免重复计次。出现冲突时保留两份证据或在可核实时合并。
- 写后回读受影响的记录与链接，核对当前进度、下一步和证据一致。只报告已经保存的内容。若只写成功一部分，交代已保存位置与待补项，无需假定其他更新成功。
